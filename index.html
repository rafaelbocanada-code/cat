ScrollTrigger.create({
  trigger: "#stage",
  start: "top top",
  end: "bottom bottom",
  scrub: true,
  onUpdate: (self) => {
    const i = Math.round(self.progress * 120);
    ctx.drawImage(frames[i], 0, 0);
  }
});

The scroll runs for 380% of the screen height. A longer stage makes the turn slower; a shorter one makes it faster.
